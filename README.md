📌 File Organization Principles

To keep the portfolio organized throughout the semester:

Use the assigned numbered folder for each topic.
Create activity-specific subfolders when an activity contains multiple files.
Use descriptive and consistent filenames.
Keep references together with the corresponding activity.
Include AI-use disclosure when required.
Avoid placing unrelated files in the root directory.
Maintain the required folder naming convention.
