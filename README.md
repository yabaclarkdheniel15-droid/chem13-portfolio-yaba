## 📖 References and Sources

Scientific information in this portfolio should be supported by credible and traceable sources.

Preferred sources include:

- Scientific textbooks
- Peer-reviewed journal articles
- PubChem
- NIST Chemistry WebBook
- Government resources
- University resources
- Safety Data Sheets (SDS)
- Recognized scientific and professional organizations

Numerical properties, safety information, unusual facts, and specialized claims should be traceable to appropriate sources.

References will be organized using **APA style** where required.

3. **Use descriptive and consistent filenames.**

6. **Avoid placing unrelated files in the root directory.**
